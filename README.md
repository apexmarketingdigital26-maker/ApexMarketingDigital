# Apex — Site completo

Site estático pronto para GitHub Pages.

## Como publicar no GitHub Pages

1. Envie todos os arquivos desta pasta para o repositório.
2. Garanta que `index.html`, `styles.css`, `script.js` e a pasta `assets/` fiquem na raiz.
3. No GitHub, vá em **Settings > Pages**.
4. Em **Build and deployment**, selecione:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Salve e aguarde o link ficar disponível.

## Arquivos principais

- `index.html`: estrutura e textos do site.
- `styles.css`: visual, responsividade e identidade.
- `script.js`: menu mobile, animações e formulário por e-mail.
- `assets/`: logos, ícones, favicon e elementos gráficos da Apex.
