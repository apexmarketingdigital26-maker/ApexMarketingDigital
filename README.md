## Publicação no GitHub Pages

1. Extraia o ZIP.
2. Entre na pasta `apex-site`.
3. Suba todos os arquivos para o repositório.
4. No GitHub, vá em `Settings` → `Pages`.
5. Em `Build and deployment`, selecione a branch principal e a pasta raiz.
6. Aguarde o link público do GitHub Pages.

## Observação

Depois de publicar, teste todos os botões e abra o link público no desktop e no celular.
